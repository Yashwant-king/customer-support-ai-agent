# Order Cancellation Policy

## Cancellation Eligibility

Customers may request cancellation of an order before the order has been delivered.

Cancellation availability depends on the current order status.

## Cancellation Request

The customer should provide:

- Order ID
- Reason for cancellation, when applicable

The support system must first verify the order in the company database.

## Orders That Can Be Cancelled

An order may be cancelled when the order has not progressed to a stage where cancellation is no longer possible.

The support agent must check the current order status before confirming cancellation.

## Orders Already Shipped

If an order has already been shipped, cancellation may no longer be available.

The customer may instead need to follow the applicable return or refund process.

## Refund After Cancellation

If payment has already been processed and the order is successfully cancelled, the refund should be handled according to the refund processing policy.

The support agent must not promise an exact refund time unless the available payment information confirms it.

## Important Rules

The support agent must never:

- Confirm cancellation without checking the order status.
- Invent cancellation eligibility.
- Promise a refund before cancellation is confirmed.
- Promise an exact refund date without supporting information.

## Escalation

Escalate to a human support agent when:

- The customer disputes the cancellation decision.
- The customer requests an exception.
- The order status does not provide enough information to determine eligibility.
