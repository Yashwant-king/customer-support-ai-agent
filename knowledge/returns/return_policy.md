# Return Policy

## Return Eligibility

Customers may request a return when the purchased product qualifies under the applicable return conditions.

The support agent must verify the order and product information before confirming return eligibility.

## Required Information

The customer should provide:

- Order ID
- Product involved
- Reason for the return

Additional evidence may be requested when necessary.

## Return Process

When a return is eligible, the customer should be provided with the applicable return instructions.

The support agent must not confirm eligibility without checking the available information and applicable policy.

## Refund After Return

If the returned product is approved for a refund, the refund should be processed according to the refund processing policy.

## Important Rules

The support agent must not:

- Guarantee return eligibility without verification.
- Promise an exact refund date.
- Invent return conditions.
- Make exceptions without authorization.

## Escalation

Escalate when:

- The customer disputes return eligibility.
- The customer requests a policy exception.
- The available information is insufficient.
