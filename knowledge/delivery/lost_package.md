# Lost Package Policy

## Possible Lost Package

A package may require investigation when it has not been delivered and the available shipping information does not explain its location.

The support agent must verify the order information before treating a package as lost.

## Required Information

The customer should provide:

- Order ID
- Description of the delivery problem

## Investigation

The support system should check available:

- Order status
- Shipping information
- Estimated delivery date
- Delivery information

The agent must not claim that a package is lost without sufficient evidence.

## Resolution

Depending on the available information, the customer may be offered an appropriate resolution such as:

- Further investigation
- Replacement, when applicable
- Refund, when applicable

The applicable replacement and refund policies must be followed.

## Escalation

Escalate to a human support agent when:

- The package cannot be located using available information.
- The customer disputes the proposed resolution.
- Replacement or refund eligibility is unclear.
- The customer requests an exception.
