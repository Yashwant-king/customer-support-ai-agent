# Delayed Delivery Policy

## Definition

A delivery may be considered delayed when the order has not been delivered by its estimated delivery date.

The support agent must verify the order information before describing an order as delayed.

## Required Information

The customer should provide:

- Order ID
- Any relevant information about the delivery problem

## Checking a Delay

The support system should check:

- Current order status
- Estimated delivery date
- Actual delivery date, if available
- Available shipping information

The agent must not assume that an order is delayed without checking the available information.

## Customer Communication

If an order is delayed, explain the available information clearly.

Do not provide a new delivery date unless the available information supports it.

## Escalation

Escalate when:

- The order remains undelivered and requires investigation.
- Shipping information is missing or inconsistent.
- The customer disputes the delivery information.
- The customer requests an exception or special handling.
